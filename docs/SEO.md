# SEO specification (binding)

Every page and feature must meet this checklist. The CI tests in `tests/Feature/Seo*` enforce the items marked ✅test.

## 0. Only the live site is indexable
Unless `SEO_INDEXABLE=true` (production, from cutover), every response carries `X-Robots-Tag: noindex, nofollow` and `robots.txt` is `Disallow: /`. Staging and local must never be indexed. ✅test

## 1. URLs: never lose an old URL
| Content | URL pattern | Notes |
|---|---|---|
| Post (old and new) | `/{slug}/` | Old posts keep their **exact** WordPress slug, including percent-encoded Bengali slugs. New posts get a **Latin transliterated** slug (e.g. `/kon-jon-tumi/`). ✅test |
| Section | `/category/{slug}/` | Same as WordPress, so no redirect is needed |
| Author | `/author/{nicename}/` | Same as WordPress |
| Issue | `/sonkha/{yyyy-mm}/` and `/sonkha/{yyyy-mm}/read/` (flipbook) | New |
| Tag | `/tag/{slug}/` | Only the ~150 controlled tags. Merged or removed tags → 301 to the section |
- **Trailing slash, always** (as on WordPress). A URL without the slash → 301 to the slashed version. ✅test
- `?p=123`, `/amp/`, `/feed/`, date archives, `/wp-content/plugins/...` and other legacy paths → 301 through the `redirects` table. Removed spam → **410**. ✅test
- Each **slug is unique** and **Unicode NFC-normalised** before saving (Bengali has visually identical forms that differ in bytes).
- A slug never changes after publishing. If an editor edits it, a 301 from the old slug is written automatically.

## 2. Every HTML page has
- A unique `<title>` (≤ 60 chars where possible) and `<meta name="description">` (≤ 155 chars). Taken from Yoast data for old posts; AI-drafted and editor-approved for new posts. ✅test
- `<link rel="canonical">` (absolute, https, trailing slash). ✅test
- `<html lang="bn">` or `lang="en"` per article; `hreflang` pairs where a translation exists.
- Open Graph + Twitter cards. `og:image` is the auto-generated 1200×630 share card (photos below 1200px are never used as og:image).
- `<meta name="robots" content="max-image-preview:large">` on articles (eligible for Google Discover).
- Breadcrumbs (visible + `BreadcrumbList`).

## 3. Structured data (JSON-LD)
| Page | Types |
|---|---|
| Home | `WebSite` (+ `SearchAction`), `Organization` (logo, sameAs), `Periodical` with **`issn: 2321-3035`** |
| Post | `Article` (stories, essays, travel) or `CreativeWork` with `genre` (poems); `author` → `Person` (guest authors included), `isPartOf` → `PublicationIssue` when the post is in an issue |
| Author | `ProfilePage` + `Person` |
| Issue | `PublicationIssue` (`issueNumber`, `datePublished`, `isPartOf` Periodical) |
- Generated by one PHP class (`App\Seo\JsonLd`), never hand-written in templates. ✅test (valid JSON, required keys).

## 4. Indexing rules
- **Indexed:** posts, sections, issues, author pages with **3 or more** published pieces, curated topic hubs.
- **noindex, follow:** author pages with fewer than 3 pieces, tag pages with fewer than 5 posts, search results, paginated pages after page 1 (they canonical to themselves, not page 1).
- **Disallowed in robots.txt:** `/admin`, `/desk`, `/submit`, `/account`, `/search`. **CSS and JS are never blocked** (the old site blocked them).
- Sitemap index `/sitemap.xml` → `sitemap-posts-{n}.xml` (≤ 5,000 URLs each, with `lastmod`), `sitemap-sections.xml`, `sitemap-authors.xml`, `sitemap-issues.xml`, plus image entries. Regenerated on publish. ✅test
- **IndexNow** ping (Bing, Yandex) on publish and update. Google is discovered through the sitemap and Search Console.
- RSS: `/feed/` (site), `/category/{slug}/feed/`, `/author/{nicename}/feed/`.

## 5. Speed (Core Web Vitals), checked in CI with Lighthouse
- Budget: **LCP < 1.8 s on mobile, CLS < 0.05, INP < 200 ms, JS < 50 KB per page**.
- Images: WebP/AVIF, `width`/`height` always set, `loading="lazy"` below the fold, `fetchpriority="high"` on the LCP image.
- Fonts: self-hosted and subset, `font-display: swap`, preload only the headline font.
- Ads: fixed-size reserved slots (no layout shift), loaded after the main content.
- Full-page cache: LiteSpeed + Cloudflare. Cache purged per URL on publish.

## 6. Content and E-E-A-T
- Real author names and bios; an About / Editorial board / Submission policy / ISSN page.
- **AI never writes the articles.** AI only drafts metadata (title variants, description, tags), and the editor approves it.
- Internal links: section, author, issue, related posts (by tags and moods), "আর্কাইভ থেকে".
- Thin and old content handled by the content audit (keep, improve, merge, noindex or 410), never silently deleted.

## 7. Launch and monitoring
- Search Console + Bing Webmaster verified before DNS cutover. Submit the sitemap on launch day.
- A 404 log in the admin panel, plus a weekly report of new 404s with suggested redirects.
- Daily Search Console check for 4 weeks after launch (coverage, CWV, traffic by page type).
